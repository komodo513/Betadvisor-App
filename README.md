## Install the Android App

Follow these steps to install the Betadvisor app on your Android device:

1. **Download the APK**:
   - Click [here](https://play.google.com/store/apps/details?id=betadvisor.betadvisor&hl=en) to download the latest `Betadvisor-v1.0.0.apk` from our GitHub Releases page.

2. **Enable Unknown Sources**:
   - On your Android device, go to `Settings > Security` (or `Settings > Apps & Notifications > Special App Access` on newer devices).
   - Enable `Install Unknown Apps` for your browser or file manager.

3. **Install the APK**:
   - Open your device’s file manager or browser downloads.
   - Tap the downloaded `Betadvisor-v1.0.0.apk` file.
   - Follow the prompts to install the app.

4. **Launch the App**:
   - Open the Betadvisor app from your app drawer.
   - Sign up or log in to access predictions, ROI analytics, and more.

**Note**: Ensure your device runs Android 5.0 (Lollipop) or higher. For security, only download the APK from our official GitHub link.
